# Sun Ground — The Magical Skull

A free, installable 2D side-scrolling platform game inspired by *Exotic Automatic*. Run, jump, punch, and fire through ten cosmic worlds based on the album’s tracks. Collect glowing skull fragments and pulse ammo, activate bridge switches, defeat each world’s boss, and bring the Magical Skull back together.

## Play

Open `index.html` or visit the GitHub Pages site. On desktop, move with **← / →** or **A / D**, jump with **Space / ↑ / W**, run with **Shift**, punch with **X / J**, shoot with **C / F**, and activate nearby switches with **E**. On phones, use the on-screen direction, run, jump, punch, shoot, and context-sensitive use buttons. Progress is saved in the current browser; no account is needed.

The game is built with HTML, CSS, and Canvas and has no build step or game-engine dependency. The album cover is used as the visual reference for the golden skull, red desert, giant sun, and cosmic night sky. Game sounds and album recordings are not required to play.

## Album and support

The album and optional support link open [Sun Ground on Bandcamp](https://sunground3.bandcamp.com/album/exotic-automatic-2). Playing is free and no purchase is needed.

## Install on a phone

Open the HTTPS GitHub Pages site, then use the browser’s **Install app** or **Add to Home Screen** option. The app shell and cover are cached after the first visit. External music and social links require a connection.
