# Sun Ground - pubblicazione e installazione

Il repository pubblico e pronto: https://github.com/luvarant-star/sun-ground-signal-hunt. I file del sito sono gia caricati.

## Attivare GitHub Pages

Resta da scegliere la sorgente di pubblicazione nelle impostazioni del repository:

1. Apri Settings -> Pages: https://github.com/luvarant-star/sun-ground-signal-hunt/settings/pages
2. In Build and deployment, scegli Deploy from a branch.
3. Seleziona il branch main e la cartella /(root), poi premi Save.
4. Attendi che GitHub mostri il link del sito. Sara https://luvarant-star.github.io/sun-ground-signal-hunt/.

Il repository e pubblico: anche il sito e i suoi file sono visibili a tutti. Per i dettagli consulta la guida ufficiale di GitHub Pages: https://docs.github.com/en/pages/quickstart

## Aggiungere l'app al telefono

Apri il link HTTPS pubblicato sul telefono:

- Android: Chrome -> menu -> Installa app o Installa e crea collegamento.
- iPhone: Safari -> Condividi -> Aggiungi alla schermata Home -> attiva Apri come app web -> Aggiungi.

La prima visita richiede internet. Il gioco e la copertina possono poi caricarsi dalla cache; Spotify e i collegamenti social richiedono una connessione.

## Limiti del prototipo

E una web app installabile, non un'app pubblicata su Google Play o App Store. Il Fan Pass salva la scelta localmente: i follow non sono verificati e l'accesso Google e una simulazione. Account reali, verifica dei follow e progressi sincronizzati richiedono OAuth/API e un backend.
